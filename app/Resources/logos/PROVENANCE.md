# Harness logos

Each harness's own mark, drawn at 128 px from the SVGs in Lobe Icons
(`@lobehub/icons-static-svg@1.102.0`, MIT, https://github.com/lobehub/lobe-icons)
with librsvg (`rsvg-convert -w 128 -h 128`): macOS's own SVG renderer blurs
Antigravity's masked gradients.

| file | source icon |
|---|---|
| claude.png | claudecode-color.svg |
| codex.png | codex-color.svg |
| agy.png | antigravity-color.svg |
| amp.png | amp-color.svg |
| grok.png | grok.svg (one colour: drawn as a template) |
| opencode.png | opencode.svg (one colour: drawn as a template) |

The marks are their owners' trademarks, shown only to name each harness.
pi has no mark here yet; Reflex draws a symbol for it.
